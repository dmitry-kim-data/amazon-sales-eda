# Amazon Sales & Product Performance EDA

Анализ датасета продаж Amazon: влияние цен, скидок и пользовательских рейтингов на популярность товаров (число отзывов).

## Стек
* Python (Pandas, Seaborn, Matplotlib, NumPy)

## Структура репозитория
* `data_cleaning.ipynb` — ноутбук с очисткой данных, визуализацией и расчетами.
* `amazon.csv` — исходные данные.
* `.gitignore` — исключение служебных файлов Jupyter и системного кеша.

## Ход работы
1. **Предобработка данных**:
   * Очистка числовых колонок (`discounted_price`, `actual_price`) от символов валют (`₹`, `,`).
   * Обработка аномальных текстовых значений (символ `|` в колонке `rating`), заполнение пропусков в `rating_count` медианой.
   * Приведение столбцов к корректным типам данных (`float64` и `int64`).
2. **Подготовка категорий**:
   * Извлечение 3-го уровня вложенности категорий (`sub_category`) из составных строк.
   * Фильтрация датасета по Top-10 подкатегориям по объему данных для сохранения репрезентативности выборки.
3. **Анализ зависимостей**:
   * Расчет матрицы корреляций.
   * Биннинг рейтингов и процентов скидок (`pd.cut`) с последующей группировкой по медианному числу отзывов (`rating_count`).

## Ключевые выводы
* **Спрос в категории Headphones**: Категория лидирует по медианному числу отзывов (~50.5k), несмотря на относительно низкий медианный рейтинг (3.95). В сегменте массовой электроники ключевым фактором объема продаж выступает цена, а не высокий рейтинг.
* **Влияние размерa скидки**: Максимальное медианное количество отзывов (~11k) наблюдается у товаров со скидкой до 30%. Установка скидок свыше 50% не приводит к росту популярности (медиана падает до 3.5k–4k отзывов).
* **Пороговые значения рейтинга**: При росте рейтинга с 3.5 медиана отзывов увеличивается с 651 до 3 453. Пик спроса приходится на диапазон ratings 4.0–4.3 (медиана 7 458 отзывов).
